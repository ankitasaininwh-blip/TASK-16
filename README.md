# Task 16: JavaScript Map & Filter Exercise

## Project Title

Student Records using JavaScript Map and Filter

## Objective

The objective of this project is to create a web page that displays
student records using HTML, CSS and JavaScript.

The project uses JavaScript map() to display student records in card
format and filter() to search students dynamically by name.

## Features

- Displays student records in card format.
- Stores student information in an array of objects.
- Displays student name, marks, class and address.
- Uses map() function to generate student cards.
- Uses filter() function to search students by name.
- Provides real-time search functionality.

## Student Object Attributes

Each student object contains:

- Name
- Marks
- Class
- Address

## JavaScript Functions

### map()

The map() function is used to generate HTML cards for every student
in the student array.

### filter()

The filter() function is used to find students whose names match the
text entered in the search box.

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Enter a student's name in the search box.
5. The matching student records will be displayed.

## Files

- index.html - Main HTML page
- style.css - Styling of the web page
- script.js - Student data, map() and filter() functionality
- README.md - Project documentation

## Result

The web page successfully displays student records and allows users
to search students dynamically by name.
